# Gist — Development Roadmap

## Phase 0: Foundation (2–3 weeks)
- Scaffold iOS app with Windsurf (SwiftUI + MVVM, TabView with 5 tabs).
- Scaffold backend (NestJS + Prisma schema + auth).
- CI/CD pipelines (lint, tests).
- Design tokens + Figma kit.

Exit: Clean builds, preview data working.

---

## Phase 1: MVP Social Core (6–8 weeks)
- Auth (email, passkeys, Apple login).
- Profiles + privacy toggles.
- Communities (create/join/leave, trending).
- Feed + recommended.
- Composer (text/link/image/video, Markdown, identity toggle).
- Threaded comments + voting.
- Moderation basics (report/block/filter).
- Notifications (replies, mentions).
- Privacy center (account deletion, EXIF stripping).

Exit: Internal TestFlight, App Store 1.2 compliance.

---

## Phase 2: Discovery + Web (6–8 weeks)
- Trending & Topics, advanced discovery.
- Search (posts, communities).
- Web app (Next.js PWA, SEO, installable).
- Moderator QoL features.

Exit: Public beta (iOS + Web).

---

## Phase 3: Scale & Quality (ongoing)
- Offline read cache, queued posting.
- Advanced automod, abuse heuristics.
- Analytics dashboards.
- iPad/desktop polish, internationalization.
